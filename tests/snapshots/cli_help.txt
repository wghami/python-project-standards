    check-commit-msg    validate a commit message file
    check-commits       validate every commit in a range
    check-pr-title      validate a PR title
    check-branch-name   validate the branch name
    check-suppressions  forbid pragmas and reasonless ignores
    check-version       version comes from tags; tags are published
    check-doc-impact    docs change with what they describe
    check-hook-parity   every hook stage also runs in CI
    check-standards     standards docs are consistent with the tooling
    check-mutation-score
                        mutation score gate
    check-template-drift
                        project is on the latest standards release
    check-hooks-installed
                        git hooks are installed
    readme              regenerate (or check) README badges and gates
    check-notebooks     notebooks: one concept each, committed executed
    check-scripts       user-facing scripts: one shape, each smoke-tested
    check-site          the deployed docs site serves every page of this build
    badge               write a shields.io badge from a gate's report
